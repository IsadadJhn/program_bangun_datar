# Geometry Calculator CLI with Python

This project is a simple Command Line Interface (CLI) application built using Python to calculate the **area** and **perimeter** of various 2D geometric shapes (*Bangun Datar*).
It is designed as a beginner-friendly project for learning Python fundamentals such as:

* Functions
* Conditional statements (`if-elif`)
* Loops (`while`)
* User input handling
* Mathematical calculations using the `math` module
* Terminal screen management with `os`

The program provides an interactive menu where users can choose different shapes and instantly calculate their properties.

---

# ✨ Features

Supported 2D Shapes:

* Square (*Persegi*)
* Rectangle (*Persegi Panjang*)
* Triangle (*Segitiga*)
* Parallelogram (*Jajar Genjang*)
* Rhombus (*Belah Ketupat*)
* Kite (*Layang-Layang*)
* Trapezoid (*Trapesium*)
* Circle (*Lingkaran*)

Available Calculations:

* Area Calculation (*Luas*)
* Perimeter Calculation (*Keliling*)

Additional Features:

* Interactive CLI Menu
* Cross-platform terminal clear (`Windows/Linux`)
* Continuous loop until user exits
* Beginner-friendly code structure

# 🚀 Installation & Usage

## Clone Repository

```bash
git clone https://github.com/IsadadJhn/Program_Bangun_Datar.git
```

## Navigate to Project Folder

```bash
cd Program_Bangun_Datar
```

## Run the Program

Ensure you have **Python 3.10+** installed.

```bash
python main.py
```
